# Network Traffic Anomaly Detection

## 1. Project Overview
This project explores network traffic data to understand the characteristics of normal and malicious traffic using Python and the CICIDS2017 dataset.

## 2. Objectives
- Explore network traffic data
- Understand dataset structure and features
- Prepare data for further analysis and anomaly detection

## 3. Dataset
- Name: CICIDS2017
- Format: CSV
- Source: Canadian Institute for Cybersecurity (CIC)

The original dataset is not included in this repository.

## 4. Tech Stack
- Python
- Google Colab
- Pandas
- GitHub
