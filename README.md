# Network Traffic Anomaly Detection
네트워크 트래픽 이상 탐지 프로젝트

## 1. 프로젝트 개요 (Project Overview)

Python과 CICIDS2017 데이터셋을 활용해 네트워크 트래픽의 특징을 분석하고, 정상 트래픽과 공격 트래픽의 차이를 파악하는 프로젝트입니다.

## 2. 프로젝트 목표 (Objectives)

- 네트워크 트래픽 데이터 구조 이해
- 데이터 전처리 및 탐색적 데이터 분석(EDA)
- 정상 트래픽과 공격 트래픽의 특성 비교
- 이상 탐지 분석을 위한 데이터 준비

## 3. 데이터셋 (Dataset)

- 데이터셋: CICIDS2017
- 형식: CSV
- 출처: Canadian Institute for Cybersecurity (CIC)
- 원본 데이터 파일은 저장소에 포함하지 않습니다.

## 4. 사용 기술 (Tech Stack)

- Python
- Pandas
- Google Colab
- GitHub
